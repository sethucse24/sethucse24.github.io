Privacy Policy - Shop Backup

Shop Backup is a personal tool used only by its owner. It is not offered to the public.

  • It uses the Google Drive permission "drive.file", so it can only see and manage the files it creates itself. It cannot see any other files in Google Drive.
  • It uploads encrypted database backup files from the owner's computer to the owner's own Google Drive, and removes old backup files that it created.
  • No data is collected, stored elsewhere, sold or shared with anyone.
  • Access can be removed at any time from Google Account → Security → Third-party apps with account access.
